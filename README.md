# Multimodal Attendance & Engagement Agent

## Overview
An AI-powered classroom attendance and engagement analytics system using Python and computer vision.

## Features
- Automated attendance tracking
- Student engagement analysis
- Computer vision-based monitoring
- Audio signal processing
- Engagement trend reports

## Technologies Used
- Python
- OpenCV
- Computer Vision
- Audio Signal Processing

## Installation
1. Clone this repository.
2. Install the required dependencies from requirements.txt, if provided.
3. Follow the project setup instructions to run the application.

Development in progress.
